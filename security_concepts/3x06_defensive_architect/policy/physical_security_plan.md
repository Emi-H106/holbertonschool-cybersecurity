# Physical & Human Security Plan

## 1. Objective

Protect the office, equipment, and sensitive information.
Start with free actions, then add improvements based on the budget.

## 2. Immediate Actions — No Additional Cost

| Problem | Action |
|---|---|
| No working visitor check-in | Assign an employee to welcome visitors and record visits on paper. |
| Visitors can walk around freely | Require an employee to accompany visitors. Receive deliveries at the entrance. |
| Server-room door is propped open | Return the fire extinguisher to its proper place. Arrange safe cooling so the door can stay locked. Until then, supervise access and monitor temperature. |
| Passwords are on the whiteboard | Remove them and change the exposed passwords. |
| Laptops are left unlocked | Require screen locking when leaving the desk. Enable automatic locking after five minutes. |
| Spare access cards are unsecured | Store them in an existing locked cabinet and record who borrows each card. Stop informal card sharing. |
| Unused switch ports are active | Identify required connections, then disable unused ports. |
| SSH private keys are shared in Slack | Set up individual access, then revoke the shared key. Prohibit sharing private keys in chat. |

## 3. Short-Term Actions — Low Cost

| Action | Purpose |
|---|---|
| Buy reusable visitor badges | Make visitors easy to identify. |
| Add restricted-area and no-photography signs | Explain the rules near the server room. |
| Label and organize cables | Reduce accidental disconnections and identify unusual connections. |
| Install a low-cost temperature sensor | Detect overheating in the server room. |
| Ask the coworking provider to repair the check-in device and cooling | Restore normal operation. Check repair costs and arrange a safe temporary solution if needed. |
| Give employees a short security briefing | Explain visitor rules, screen locking, and safe handling of passwords. |

## 4. Long-Term Actions

| Action | Purpose |
|---|---|
| Use a suitable server room with reliable cooling | Protect equipment without leaving doors open. |
| Give employees individual access cards | Identify who enters and revoke access individually. |
| Limit server-room access to authorized staff | Apply the principle of least privilege. |
| Review access rights and remove access when employees leave | Prevent unnecessary or outdated access. |
| Separate guest Wi-Fi from employee and server networks | Limit what visitors can access. |
| Repeat training and include it in onboarding | Make security part of everyday work. |

## 5. Training — The "Delivery Guy TikTok" Situation

### Immediate Response

1. Politely ask the delivery person to stop filming.
2. Explain that the server room is restricted.
3. Escort them back to the delivery area.
4. Report the situation to the Office Manager and security lead.
5. Record what may have been filmed and whether equipment was touched.
6. Request removal of published footage if it exposes sensitive information.
   Change any exposed passwords.

Do not take or operate the person's phone.
Filming alone does not prove malicious intent.

### Employee Training

| Topic | Expected Behavior |
|---|---|
| Visitors | Check who they are meeting and accompany them inside the office. |
| Deliveries | Receive packages at the entrance, away from servers. |
| Tailgating | Do not let unknown people follow employees through secure doors without checking in. |
| Photography | Report unauthorized filming in restricted areas. |
| Workstations and passwords | Lock screens and keep credentials private. |
| Reporting | Report mistakes or suspicious situations quickly. |

Use this situation as a training example without blaming people
for reporting it. The open door and missing visitor controls
must also be fixed.

## 6. Responsibilities

| Person or Team | Responsibility |
|---|---|
| Office Manager | Manage visitors, access cards, and building repairs. |
| IT Team | Manage screen locks, network ports, credentials, and server safety. |
| Security Lead | Organize training and check that actions are completed. |
| All Employees | Follow the rules and report security problems. |
